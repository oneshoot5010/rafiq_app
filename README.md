# رفيق — تطبيق ديني إسلامي (نواة المشروع)

مشروع Flutter حقيقي يحتوي على المميزات الأساسية شغّالة بمنطق **Offline-First**:
كل الحسابات (مواقيت الصلاة، القبلة، التقويم الهجري) تتم على الجهاز مباشرة
بدون أي اتصال بالإنترنت أو أي API خارجي.

## المميزات المُنفّذة في هذه النواة
- ⏰ مواقيت الصلاة (حساب فلكي محلي، طريقة قريبة من رابطة العالم الإسلامي)
- 🧭 اتجاه القبلة (حساب الزاوية من إحداثياتك إلى الكعبة)
- 📿 عداد التسبيح (يُحفظ محليًا حتى لو أغلقت التطبيق)
- 📅 التقويم الهجري (تحويل حسابي تقريبي من الميلادي)

## المتطلبات لتشغيل المشروع
1. تثبيت [Flutter SDK](https://docs.flutter.dev/get-started/install)
2. التأكد من `flutter doctor` بدون أخطاء حرجة

## خطوات التشغيل
```bash
cd rafiq_app
flutter pub get
flutter run
```

## أذونات لازم تضيفها يدويًا (للموقع الجغرافي)

**Android** — في `android/app/src/main/AndroidManifest.xml` أضف قبل `<application>`:
```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
```

**iOS** — في `ios/Runner/Info.plist` أضف:
```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>نحتاج موقعك لحساب مواقيت الصلاة واتجاه القبلة بدقة</string>
```

## الخطوات التالية المقترحة (المرحلة الثانية)
- إضافة نص القرآن الكريم كاملًا (ملف JSON محلي) + شاشة قراءة
- إضافة الأذكار والأدعية كملفات بيانات محلية
- إضافة حزمة `flutter_compass` لبوصلة قبلة تفاعلية حية
- إضافة نظام تتبع الحفظ بخوارزمية Spaced Repetition
- إضافة حاسبة الزكاة

## ملاحظة مهمة
خوارزميات مواقيت الصلاة والتقويم الهجري هنا **تقريبية بدقة معقولة**
للاستخدام العام. للمواعيد شديدة الحساسية (كبداية رمضان رسميًا)، يُفضّل
لاحقًا مطابقتها مع إعلانات دار الإفتاء أو مصدر رسمي معتمد في بلدك.
